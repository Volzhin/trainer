# Trainer — прототип фитнес-приложения

Рабочий прототип клиентской части по `tz.md`: offline-first PWA-трекер силовых
тренировок с нативным ощущением интерфейса, готовый к упаковке в Capacitor.

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173

npm run build        # прод-сборка + Service Worker
npm run preview      # проверка офлайн-режима (см. ниже)
```

Стек: React 18 + TypeScript + Vite, Dexie.js (IndexedDB), Workbox через
`vite-plugin-pwa`, React Router. Внешних UI- и chart-библиотек нет — графики
рисуются SVG, чтобы бандл оставался лёгким для WebView.

## Что реализовано

**Offline-first.** Локальная база — источник истины. Приложение полностью
работает с выключенным сервером: каталог, программы, логирование, аналитика.
Проверено на прод-сборке при остановленном сервере, включая глубокие маршруты.

**Тренировочный движок** (`src/pages/LiveSession.tsx`) — самый нагруженный экран:
- ввод веса и повторений в два касания, подтверждение подхода одной кнопкой;
- автоподстановка весов и повторений из прошлой такой же тренировки;
- таймер отдыха с вибрацией, звуком и локальным уведомлением; время берётся
  из шаблона упражнения, при его отсутствии — из настроек профиля;
- «горячая замена» упражнения, если тренажёр занят, без потери введённых данных;
- автоматическая фиксация личного рекорда по расчётному 1ПМ (формула Эпли);
- плашка «тренировка идёт» на других вкладках — как в нативных плеерах.

**Каталог упражнений** — 72 предустановленных упражнения на русском с описанием
техники, фильтрами по мышечной группе и оборудованию, поиском и созданием
собственных упражнений.

**Программы** — 4 готовых сплита платформы (Full Body, Push/Pull/Legs, Сила 5×5,
домашние тренировки) и конструктор своих: дни, упражнения, целевые подходы,
повторения и время отдыха. Лимит бесплатного тарифа — 3 своих программы.

**Аналитика** — тоннаж по неделям, календарь тренировок, распределение объёма
по мышечным группам за 30 дней, топ рекордов 1ПМ, график 1ПМ по каждому
упражнению, замеры тела с кривой веса.

**Профиль** — тариф FREE/PRO, настройки отдыха, вибрации, звука, уведомлений,
экспорт истории в CSV, счётчики локальных данных и очереди синхронизации.

## Соответствие требованиям ТЗ

| Требование ТЗ | Где реализовано |
|---|---|
| Разделение шаблона и факта выполнения | `WorkoutTemplateItem` vs `ExerciseSet` в `src/db/db.ts` |
| UUID вместо автоинкремента | `uid()` во всех сущностях |
| LWW-разрешение конфликтов | поле `updated_at` во всех таблицах |
| Очередь фоновой синхронизации | `syncQueue` + `enqueue()`, `backgroundSync` в `vite.config.ts` |
| Тактильный отклик | `src/lib/native.ts` — обёртка, подменяемая на `@capacitor/haptics` |
| Уведомления в контексте использования | разрешение запрашивается при первом отдыхе, не на старте |
| Нативная навигация | нижний таб-бар, модальные шторки, safe-area insets |
| Гость без регистрации | всё работает локально, вход нужен только для облака |
| Локальные платежи | экран оплаты через СБП / ЮKassa (эмуляция) |

## Чего в прототипе нет

- **Сервера.** Prisma-схема из ТЗ отражена в структуре локальной базы, но
  Node.js API, PostgreSQL и реальная синхронизация не поднимались — очередь
  мутаций копится локально и её некому разбирать.
- **Реальной авторизации** (VK ID, Яндекс ID, Apple, Google) — экран есть,
  провайдеры не подключены.
- **Реальных платежей** — кнопка оплаты переключает тариф локально. В проде
  права выдаёт RevenueCat по вебхуку от эквайера или RuStore.
- **Capacitor-обёртки** — код к ней подготовлен (все нативные вызовы изолированы
  в `src/lib/native.ts`), но `npx cap add ios/android` не выполнялся.
- **Видео техники упражнений** — на карточке заглушка под CDN.
- **Суперсетов** — поле `superset_group` в схеме есть, интерфейс группировки нет.
- **AI-генерации программ и социальной ленты** — по ТЗ это четвёртый этап.

## Проверка офлайн-режима

```bash
npm run build && npm run preview
# открыть http://localhost:4173, дождаться регистрации Service Worker,
# остановить сервер и перезагрузить страницу — приложение откроется из кеша
```

В dev-режиме Service Worker отключён намеренно (`devOptions.enabled: false`),
иначе кеш мешает горячей перезагрузке.

## Структура

```
src/
  db/       db.ts — схема IndexedDB; seed.ts — каталог и программы; repo.ts — операции
  lib/      calc.ts — 1ПМ, тоннаж, форматирование; native.ts — хаптика/звук/уведомления
  store/    app.tsx — таймер отдыха, тосты, статус сети
  components/ TabBar, RestTimer, ExercisePicker, Sheet, LineChart, Icons
  pages/    Home, Programs, ProgramDetail, Exercises, ExerciseDetail,
            LiveSession, SessionDetail, Progress, Profile
```
