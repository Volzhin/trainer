# Trainer

Офлайн-первое PWA для тренировок: React 18 + TypeScript + Vite, Dexie
(IndexedDB) как источник правды на устройстве, PocketBase на сервере.

Подробности — в `DEPLOY.md` (устройство, деплой, схема базы, синхронизация)
и `DESIGN.md` (дизайн-система: токены, утилиты, правила). Прочитайте их,
прежде чем менять что-то за пределами одного экрана.

## Перед выкладкой — сверка с origin

В `main` пишут несколько человек параллельно, защиты ветки нет, а каждый
пуш деплоится в прод сразу. Поэтому **перед любым пушем**:

```bash
git fetch origin
git log --oneline main..origin/main   # не пусто — сначала git pull --rebase
```

Само расхождение git отобьёт и без сверки — пуш просто перестанет быть
fast-forward. Сверка нужна раньше: чтобы узнать о чужих правках **до**
того, как вы час пишете поверх устаревшего кода. Пересекаются чаще всего
в `src/index.css` и `src/tokens.css` — их трогает почти любая задача по
внешнему виду.

После `git pull --rebase` **обязательно пересоберите**: конфликт разрешён
руками, и это ровно тот случай, когда git уже ничего не проверяет, а пуш
уезжает в прод. Пуш с `--force` в `main` — никогда.

## Проверки

```bash
npx tsc -b        # обязательно
npm run build     # то же самое сделает деплой
```

Оба должны проходить до коммита. Локальный хук `.git/hooks/pre-push`
гоняет `tsc` сам перед выкладкой в `main`; хук не в репозитории, на новой
машине ставится заново (см. `DEPLOY.md`).

## Чего не делать

- Не выкладывать руками через `rsync`/`scp` — следующий деплой затрёт.
- Не править схему PocketBase кликами в админке: только `server/schema.mjs`.
- Не переписывать уже выпущенную версию Dexie в `src/db/db.ts` — нужна новая.
- Не коммитить доступы «временно»; `ssh.md` в `.gitignore` намеренно.
- Не работать на живых данных клиентов: требования 152-ФЗ не реализованы,
  сервер вне аттестованного контура. Только тестовые аккаунты.

## Стиль

Комментарии в коде — по-русски, объясняют **почему**, а не что. Внешний вид
задаётся только токенами и классами из `src/tokens.css` и `src/index.css`;
цвет, отступ или радиус числом в `style=` — повод завести класс.
